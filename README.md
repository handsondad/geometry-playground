# 几何游乐场

一座中文互动几何实验室，参考「科学小游戏大冒险」的展馆式组织方式。所有实验都在浏览器中运行，不需要账号、后端或外部资源。

| 展馆 | 可以动手做什么 |
| --- | --- |
| 平面几何与尺规 | 《几何原本》第一卷九道互动命题：等边三角形、角与线段平分、两类垂线、复制角、平行线、三角形内角和及勾股定理；另有三角形中心与日本算额题。 |
| 立体与空间 | 平移切面，改变观察方向，看看切正方体能不能切出正六边形。 |
| 坐标、方程与曲线 | 调整两颗钉子的距离，拖动笔尖画出绳长恒定的椭圆。 |
| 变换、对称与透视 | 比较旋转、反射和缩放；用镜像瞄准台球；画旋转和镜像图案。 |
| 镶嵌与离散几何 | 将不同的砖贴在同一个顶点，试着拼满 360°。 |
| 非欧几何与曲率 | 改变球面三角形的经度差；在庞加莱圆盘里比较测地线，拖顶点测角亏。 |
| 拓扑与连续变形 | 对比沿中线剪开普通纸环和莫比乌斯带的结果。 |
| 分形与自相似 | 迭代科赫雪花、谢尔宾斯基三角形，或调整分支规则让分形树长大。 |
| 计算几何与算法 | 拖动服务站和市民，观察沃罗诺伊区域与最近匹配。 |
| 高维几何 | 观察四维超立方体旋转后的投影，移动 w 切面，比较三维截面。 |

参考「科学小游戏大冒险（sci-playground）」与「拼波大冒险（fourier-puzzle-game）」的父子互动教学方式：首页设有「小念和爸爸」互动开场、全局探索进度条、关键词检索与「随便玩一个」，十座展馆都有开场导览、「几何百宝箱」（大师故事与居家小实验）以及「小念问爸爸」专题问答；全部 26 个互动实验均配有三轮「小念问爸爸」图文动画引导与离线双人语音。

答对实验的小挑战即可点亮该实验并触发庆祝反馈。进度与声音开关保存在当前浏览器，不会上传。动态实验也支持选中顶点后按方向键移动。

新增实验的灵感来自 [hands-on-dad 的数学资源收藏](https://github.com/handsondad/hands-on-dad/blob/main/content/steam.md#L599)，具体参考页标注在各实验内。

《几何原本》从卷 I 选读，不把尚未实现的命题冒充已上线内容。命题页列出依赖并连接 Joyce 的英译原文；图文联动与拖点验证借鉴 C82、Manim Euclid Elements 和 geomlib，图形、讲解与实现均为本站独立编写。

所有 26 个实验均有三轮「小念问爸爸」：先问、追问、自己验证。对话可以驱动同一画板的作图、切片、分形迭代或证明高亮动画，不会抹掉已有的手工作图进度。语音可选、不会自动播放，音频已随项目保存，不依赖浏览器在线合成。

## 本地运行

需要 Python 3 和 Node.js 22+；无需安装 npm 依赖。

```powershell
npm run dev
```

访问 <http://127.0.0.1:8000/>。静态部署可直接发布 `index.html`、`style.css`、`src` 和 `public` 目录。

修改对话文字后，可在安装 `edge-tts` 的 Python 环境中运行以下命令更新语音：

```powershell
python .\tools\generate-elements-voice.py
python .\tools\generate-all-voice.py
```

```powershell
npm test
```
