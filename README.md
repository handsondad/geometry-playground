# 几何游乐场

一座中文互动几何实验室，参考「科学小游戏大冒险」的展馆式组织方式。所有实验都在浏览器中运行，不需要账号、后端或外部资源。

| 展馆 | 可以动手做什么 |
| --- | --- |
| 平面几何与尺规 | 《几何原本》第一卷九道互动命题：等边三角形、角与线段平分、两类垂线、复制角、平行线、三角形内角和及勾股定理；另有三角形中心、日本算额题和半圆里的直角（泰勒斯定理）。 |
| 立体与空间 | 切正方体，比较同边数的截面；把方柱推斜，对比同高截面与体积；把正多边形围在顶点上，看为什么只有五种柏拉图立体；折叠展开图，看哪张能合成正方体。 |
| 坐标、方程与曲线 | 用钉子和绳子画椭圆；滚轮描出摆线；倾斜切平面，从双圆锥切出四种曲线；按乘法表连弦，围出心形线和肾形线。 |
| 变换、对称与透视 | 比较旋转、反射和缩放，借镜像瞄准台球或绘图；从小孔相机里测量铁轨的透视；调种子的转角，看黄金角怎样排出斐波那契螺旋。 |
| 镶嵌与离散几何 | 用不同的砖试着拼满 360°；连起蜂窝中心，找出等边三角网；细分彭罗斯镶嵌，看胖瘦之比逼近黄金比；在钉板上数格点算面积（皮克定理）。 |
| 非欧几何与曲率 | 改变球面三角形的经度差；在庞加莱圆盘里比较测地线，拖顶点测角亏；选 {p,q} 铺双曲镶嵌，把七边形拖向边缘。 |
| 拓扑与连续变形 | 对比沿中线剪开普通纸环和莫比乌斯带；拉斜纸面、改网格、挖洞，比较欧拉示性数；走哥尼斯堡七桥，数奇数陆地；从迷宫里射出射线，数穿过几次判断里外。 |
| 分形与自相似 | 迭代科赫雪花、谢尔宾斯基三角形和分形树；玩混沌游戏，对比随机跳点如何铺满正方形却在三角形留出空洞；把纸条一次次对折，展开成龙形曲线。 |
| 计算几何与算法 | 用沃罗诺伊图划服务区；拖动点跨越边界，观察凸包怎样改变；拖动站点看德劳内三角网和空外接圆；在梳子形展厅里摆保安，看美术馆定理。 |
| 高维几何 | 从点逐维复制到五维；再旋转四维超立方体，比较投影与三维截面；让球和正方体穿过平面国；一维一维接出 n 维立方体的对角线 √n。 |

首页先是一组几何明星轮播，每座展馆一张：莫比乌斯带、彭罗斯镶嵌、四维超立方体、乘法表里的心形线、双曲七边形镶嵌、科赫雪花、五种柏拉图立体、向日葵的黄金角、沃罗诺伊图，还有一个能拖动的尺规等边三角形。画面和下方读数都是实时算出来的，比如彭罗斯镶嵌的胖瘦三角形之比逼近黄金比 1.618，双曲镶嵌每个角始终是 120°。每张配一句介绍、所在展馆和一块游乐场的入口，并注明 Wolfram MathWorld 出处。轮播 8 秒换一张，可以暂停，鼠标停在上面时也会停下。往下可以搜索问题、随便问一题，或者从十座展馆进入。展馆里的问题按入门、进阶、挑战分组，下面是这座馆的游乐场和几何故事。全站有 50 个动画问答及对应游乐场、21 篇故事，除平面几何馆外每座展馆至少有 4 块游乐场。非欧几何展馆还可进入「曲率对照台」。

每道问题有一页问答：左边是小念和爸爸的对话，右边是几何动画（手机上动画在对话上方）。每轮对话是一幕，爸爸开口时画板演示对应的场景；可以连播，也可以点某一轮的「🎬 看这一幕」单独看。关闭声音仍可看动画和字幕。看完会记为「看过」。

想亲手操作就点「换我动手」进入游乐场。游乐场是一块独立的大画板，配有操作台和三个「摆出画面」按钮，可以一键摆出对话里的三个场景再接着拖。答对游乐场的小挑战即可点亮它并触发庆祝反馈。进度与声音开关保存在当前浏览器，不会上传。可拖动的点也支持选中后按方向键移动。

旧版链接（`#lab/…`、`#question/…`、`#reading`）会自动跳到新地址。

灵感来源包括 [hands-on-dad 的数学资源收藏](https://github.com/handsondad/hands-on-dad/blob/main/content/steam.md#L599)、MIT CSAIL、OpenStax 和 Wolfram MathWorld。具体资料可在相关实验页的「爸爸的观察笔记和资料」里查看。

《几何原本》从卷 I 选读，不把尚未实现的命题冒充已上线内容。命题页列出依赖并连接 Joyce 的英译原文；图文联动与拖点验证借鉴 C82、Manim Euclid Elements 和 geomlib，图形、讲解与实现均为本站独立编写。

音频已随项目保存，不依赖在线合成。

## 本地运行

需要 Node.js 22+。页面用 React + TypeScript + Vite 搭建，几何实验本身是原生 JavaScript 和 SVG。

```powershell
npm install
npm run dev
```

访问 <http://127.0.0.1:8000/>。

```powershell
npm run check   # 仓库规则
npm test        # 几何与数据测试
npm run build   # 打包到 dist/
npm run smoke   # 无头浏览器巡检全部页面
```

部署时发布 `dist/` 目录即可，GitHub Actions 会在推送 `main` 后自动完成。

修改对话文字后，可在安装 `edge-tts` 的 Python 环境中运行 `npm run voice` 更新语音。
